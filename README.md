# Workforce Data Analysis – SQL

## Project Overview
This project focuses on workforce data analysis using SQL Server. It analyzes salary trends, job titles, experience levels, employment types, company locations, company sizes, and remote work patterns.

## Project Title
Case Study on Workforce Data Analysis: Salary and Remote Work Trends Across Job Titles and Company Locations

## Tools & Technologies
- SQL Server / MS SQL Server
- SQL
- Microsoft Excel
- GitHub

## Dataset
The project uses the Salaries dataset containing information about:
- Work Year
- Experience Level
- Employment Type
- Job Title
- Salary
- Salary Currency
- Salary in USD
- Employee Residence
- Remote Ratio
- Company Location
- Company Size

## Key Analysis
The project covers:
1. Job market analysis based on company size
2. Average salary analysis by job title
3. Salary comparison by country and experience level
4. Salary growth analysis
5. Remote work analysis
6. Salary updates based on experience level
7. Employment type analysis
8. Company size and location analysis
9. Fully remote salary analysis
10. Salary trends and workforce insights

## Project Objectives
- Analyze salary trends across different job roles.
- Compare salaries based on experience levels and locations.
- Identify countries with higher salary opportunities.
- Analyze remote work patterns.
- Support workforce planning and salary benchmarking.

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- HAVING
- ORDER BY
- Aggregate Functions
- CASE Statements
- Subqueries
- CTEs
- UPDATE
- Joins
- Window Functions

## Conclusion
This project provides insights into salary patterns, remote work trends, job roles, experience levels, and company locations. The analysis can help organizations with workforce planning and salary benchmarking and can also help professionals understand salary opportunities across different markets.
